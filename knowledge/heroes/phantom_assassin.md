# Phantom Assassin

> Hidden knowledge source. Retrieve selectively; never dump this file into the dashboard.

## Identity
Assassination/scaling carry: use Blur/map ambiguity and Phantom Strike access to delete a priority target once defensive answers are solved.

## Skills
- Stifling Dagger: secure lane resources and safely apply attack modifiers.
- Phantom Strike: access + burst window; do not spend it where the exit/kill is unclear.
- Blur: farming/map-pressure tool as well as defense; exploit information denial.

## Items
- Choose farming acceleration versus earlier Desolator tempo from lane/draft state.
- BKB is often the permission-to-hit item, not an optional luxury.
- Basher/Abyssal, Satanic/dispel, Nullifier, MKB or break are conditional solutions after core damage/access.

## Neutral Items
- Raw damage/attack speed amplifies burst when survivability is already solved.
- Defensive/status-resistance choices are better when one disable decides the fight.
- Mobility/access value is lower if Phantom Strike already reaches the correct target reliably.

## Draft Fit
Prefer when enemy supports/cores can be isolated and lack reliable saves or anti-burst. Be cautious into heavy armor, break, evasion/miss, instant disables and multiple saves.
